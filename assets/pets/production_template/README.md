# Production pet template

Copy this directory to `assets/pets/<pet_id>/` before creating a new original
Godot-rigged pet. It is a contract and workflow template, not a playable pet:
it intentionally contains no character art and must not be marked `approved`.

- `source/`: licensed reference record
- `parts/`: approved transparent body-part source files
- `rig/`: per-pack rig-part contract only
- `animations/`: authored animation definitions
- `metadata/`: `pet_manifest.json`
- `review/`: human visual-review evidence and checklist
