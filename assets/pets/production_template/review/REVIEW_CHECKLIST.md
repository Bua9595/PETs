# Production pet review checklist

Status flow: `draft` -> `needs_review` -> `approved`, or `draft` /
`needs_review` -> `rejected`.

- Every body part is fully visible in idle and action keyframes.
- No white fringe, background, accidental crop, missing hand, or missing foot.
- Anatomy, proportions, palette, line treatment, and face are consistent.
- Each joint has the manifest-specified overlap reserve in every tested pose.
- Pivot locations and layers match the rig contract.
- `idle_breath`, cursor look, and `wave` have been visually tested.
- Only a reviewer can set `status` to `approved`.
