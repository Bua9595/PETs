# Blue Fox source references

`master_figure_reference.png` is the user-supplied primary visual reference from
2026-08-10 at 23:23. It is authoritative for proportions, eye spacing, head and
body balance, clothing geometry, open hand silhouette, footwear separation,
palette, and tail placement.

`alternate_hand_reference.png` is the earlier original reference generated in
this development run with OpenAI's built-in image-generation tool. It is now
audit-only: its fully covered glove treatment did not remain readable at the
desktop render size. The primary reference controls both hand proportions and
the final fingerless treatment.

`previous_contrast_reference.png` is the superseded user-supplied contrast
reference retained for audit history. It no longer drives the current artwork.

The 22 production parts are deterministic project-native SVG interpretations
of the current combined direction. The SVG files are the rig sources of truth;
none of the PNG references is an automatically sliced sprite sheet. The pack
remains `draft` until the assembled result passes visible review.
