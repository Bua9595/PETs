# Blue Fox production pet

`pet001_blue_fox` is the first original character built directly for the
manifest-driven Godot rig pipeline. It is not derived from Ruffy, PET2, or an
older pose sprite.

The pack is currently `draft`. Its authoritative design reference was replaced
on 2026-08-10 at 23:23 after the preceding assembled render failed visual review.
The current direction uses bright layered blue fur, orange inner ears, separated
teal eyes, a compact royal-blue hoodie, dark shorts, open fingerless gloves,
separated sneakers, and a cream-tipped tail behind the right arm.

Technical validation and headless Godot checks do not replace the required
visible Windows review of this revised asset set.

- `source/`: primary design reference, alternate hand reference, and provenance
- `parts/`: 22 transparent SVG rig parts, including a separately layered tail
- `rig/`: pack-specific pivot, layer, and tail notes
- `animations/`: intended animation contract
- `metadata/`: version-1 production manifest
- `review/`: current automated and manual review state
