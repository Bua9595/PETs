# Ruffy Gear3 Source Rejected

## Decision

The current Gear3 re-extraction is rejected as a source set.
No candidates are approved.

## Reasons

- too many anatomy errors
- illogical thumb-bite / air-inhale poses
- giant limbs overlap cells
- visible neighboring fragments
- unsafe cut boundaries
- some hands/fingers are malformed
- some arm paths are anatomically implausible

## Known Examples

- `ruffy_gear3_reextract_0002`: bad thumb-bite logic
- `ruffy_gear3_reextract_0012`: six-finger/anatomy error
- `ruffy_gear3_reextract_0009`: implausible arm path

Generate a new Gear3 source sheet in smaller controlled batches.
